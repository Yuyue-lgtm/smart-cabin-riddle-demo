## 三层边界

| 层级 | 负责内容 | 经验库不能替代的部分 |
| --- | --- | --- |
| 硬规则与可信状态 | 判题、防剧透、暂停与恢复、优先级仲裁、事件门槛、动作授权、过期及作用域校验 | 不因检索到经验而解除暂停、增加次数、改变答案或扩大权限 |
| 主持经验 | 是否鼓励、留白、邀请、轻声承接、应景回应或温和收尾；组织自然语言 | 不生成传感器事实，不把示例中的属性、座位、时间当当前事实 |
| 执行器与回执 | 前端校验并模拟执行允许动作，输出真实成功或失败状态 | 模型动作计划不等于成功；不凭一句“已关闭”认定设备执行 |

普通乘客可授权背景音乐、明确分区照明及现有玩家暂停/继续；继续只解除用户主动暂停。分区照明与答对氛围灯不是同一能力。普通空调、分区音量、换主题及 ETA 查询仍不可执行；睡眠关怀使用独立有效事件授权。答对氛围灯仍由现有前端规则执行。

## 经验变化

| ID | 补强重点 | 典型区别 |
| --- | --- | --- |
| HK01 | 困难先承接，只复盘公开线索；否定属性回答不计猜错 | “帮帮我”可鼓励；“但让我再想想”转留白 |
| HK02 | 反复索要也不多透露一点，示例明确公开事实来源 | 缺少公开线索不能从答案补线索；默认策略改为守卫允许的 `encourage` |
| HK03 | 独立思考不被困难、沉默或换题撤销 | 不追加提示、追问和协作邀请 |
| HK04 | 邀请按实际身份和允许名单，不按黄金线指定 | 左后睡着不能叫醒，改邀右后需征求同意；副驾不自动代答 |
| HK05 | 睡眠关怀、用户记忆温度、醒来恢复及手动覆盖 | 分区音量零不等于关全局音乐；睡前灯关闭则不强制开灯 |
| HK06 | 区分环境回应、超速提醒与主驾疲惫安全表达 | 换环境不换当前谜底；车库/隧道不承诺专属题；不靠游戏提神 |
| HK07 | 混合意图、澄清、“我这边”及现有暂停权限 | 左后说“我这边”不是副驾；“它会关灯吗”不是控制请求 |
| HK08 | 多事件打断、揭晓恢复和过期结果 | 固定等待不证明道路安全；原在揭晓则继续揭晓，不重开题 |
| HK09 | 到达提醒、ETA 查询和黄金线结束分离 | 快到目的地不等于剩两分钟；五分钟脚本结束不强制结算 |
| HK24 | 车内欢笑、轻声接梗与自然回游戏 | 睡眠中仍可轻轻承接其他人，不开音乐、不叫主驾抢答 |
| HK25 | 认错座位、环境或问题后的短修复 | 同为青年或长辈仍按座位区分，不能用旧会话覆盖当前身份 |
| HK26 | 当前快照优先及真实用户偏好 | 模拟乘客台词不改变真实副驾偏好；跨题不串谜底和公开事实 |
| HK28 | 副驾低压力邀请的既有授权条件 | 不能因后排睡着或黄金线到点就代替副驾发言 |

## 五条线覆盖

| 体验线 | 重点组合 | 主持上的区别 |
| --- | --- | --- |
| A 城市风景亲子游 | HK01–HK08、HK24、HK26 | 用实际儿童身份表达，简单但不额外泄露线索；睡眠、急刹与后续环境共同保留 |
| B 赛博城市朋友夜游 | HK04–HK09、HK24–HK26 | 夜游可接梗，超速和复杂路段不玩安全梗；隧道不默认开灯，醒来不覆盖已关闭音乐 |
| C 雪景雨天长辈同行 | HK01–HK09、HK26 | 尊重长辈但不刻板化；“好冷”仍无普通调温权限，“让我想想”优先于主动帮助 |
| D 傍晚深夜家庭返程 | HK03、HK05–HK09、HK24 | 婴儿只参与状态，不安排发言；疲惫主驾不邀请，醒来不是必然加入 |
| E 风景归城家人同行 | HK01–HK09、HK24–HK26 | 环境、睡眠、驾驶状态先后叠加；每次接续读最新快照，不重复动作或补播旧回答 |

## 环境表达边界

| 当前环境 | 可参考的主持方式 | 不应额外推断 |
| --- | --- | --- |
| 车库 | 简短承接当前地点，正常等待游戏进程 | 已驶上公路、已有车库专属题 |
| 隧道 | 承接光线场景变化，保持当前题 | 必须开照明、网络已断、已经安全驶出 |
| 雪景 | 温和应景，不根据环境推断乘员体感 | 所有人都冷、应该关空调或当前谜底是雪人 |
| 雨天 | 简短承接雨景，不展开安全预测 | 已收到急刹、道路已安全或下一题必定是雨伞 |
| 城市白天 | 当前城市环境的一句自然回应 | 已到目的地、下一题答案 |
| 城市夜晚 | 适度轻松但守住安静和驾驶约束 | 自动打开背景音乐、邀请疲惫主驾 |
| 风景区 | 可呼应窗外景色，继续当前题 | 自动更换本题、把风景词变成未公开属性 |
| 傍晚 | 语气放缓但不主动改变设备 | 所有人该睡、必须调灯或调温 |
| 深夜 | 尊重睡眠状态及简短表达偏好 | 全车已睡、真实用户不愿参与或主驾安全已恢复 |

主题只有在实际选题确认后才介绍，不从知识库生成谜底；环境切换时的串词与下一题开场是两个已有入口，不因双屏延迟重复到达提醒。
