# 91题分配规则

2026-10-22。本地已接入；本轮未发布线上，未保存或发布Dify工作流。

## 题库来源

- 通用池53道：`RIDDLE_BANK_53_TAGGED_V1.json`。使用用户确认的闪电、蜜蜂、咖啡、耳机、长城最新稿，其余提示不改。
- 环境专属池38道：`ENVIRONMENT_RIDDLE_BANK_V2.json`。雪景8、雨天7、城市白天5、城市夜晚5、风景区5、傍晚4、深夜4。保持用户给定分组，包括城市白天的霓虹灯。
- 不合并旧35题草稿，不保留已不在这两批清单中的方向盘、草原等旧谜底。
- `tools/build-riddle-bank.mjs` 将两份JSON编译进前端的明确标记区，不新增启动网络依赖。修改题库后运行该命令；`--check` 检查文档数据与运行数据是否一致。不能手改生成区。
- ID用于历史和持久化，数组位置只用于现有运行接口。前8个旧索引保留，判题不依赖索引代表的固定谜底。

## 每局六题

| 题号 | 难度目标 | 编排目的 |
| --- | --- | --- |
| 1 | 简单 | 暖场，首题也按匹配度抽选，不再固定谜底 |
| 2 | 简单 | 继续建立参与感 |
| 3 | 中等 | 逐步增加推理 |
| 4 | 中等 | 保持互动 |
| 5 | 中等或挑战 | 亲子、长辈默认中等；朋友约65%优先挑战，通用人群约40%优先挑战 |
| 6 | 简单或中等 | 约60%优先简单，轻松收尾，不主动选挑战 |

人群以当前乘客关系为准，不只看体验线名称。例如“风景归城家人同行”的现有乘客关系是年轻朋友，按朋友配置处理。

目标是4道当前环境专属题、2道通用题，但不强凑。优先在第1、2、4、5题安排专属题；若前面车库等环境不能出专属题，后续会尝试补足。题库中部分环境没有足够的中等题或挑战题，保持节奏和去重优先，允许比例偏离4:2。通用题即使带有环境软标签，也计入通用池，不混算专属配额。

## 选择顺序

1. 排除本局已开始的题和正在准备后续题时的当前题，绝不重复。
2. 专属题只从当前精确环境中选择。天气优先于地点，深夜和傍晚优先于泛风景；城市昼夜分开。车库、隧道不借用其他环境专属题，回退通用池。
3. 优先排除本地最近12次实际出题。先允许使用其他合适的通用题，只有所有可用未出题都在近期记录中，才放宽近期限制；仍不放宽本局去重。
4. 在新鲜候选中匹配本轮难度；没有该难度时按邻近难度补足，优先低于目标而不是把首题升级成挑战。
5. 在相同难度中匹配专属/通用配额；目标池不足则使用另一池。
6. 同等级同池存在替代时，避免连续相同类别；文具、数码、日常户外合并为“日常用品”做连续性检查。确实没有替代时不因此卡住。
7. 剩余候选加权抽取：环境标签匹配×3、人群匹配×2.5或通用人群×1.4、推荐体验线×1.5、目的地主题匹配×3。目的地覆盖迪士尼、夜市、草原、观星露营等当前主题。

采样由游戏ID和选题上下文生成稳定随机值。不同新局会变化；同一局同一题、同一环境类别、目的地、乘客关系和已出题集合不重新抽选。近期限制被迫放宽时，越近出现的题权重越低。

## 稳定性边界

- 当前题开始后，不因切环境更改谜底、提示、次数、事实或当前预演。切环境只安排下一题；快速连续切换仍等待800ms，仅处理最终环境。
- 相同选题复用已有预演，重复重绘和刷新准备操作不重复请求。确实换题才取消旧预演；旧响应保留原有身份、局号、轮号隔离，不能覆盖新题。
- 当前题结束时再次核对最新环境；若防抖尚未到期，换题边界直接按最新环境确定，然后取消旧计时。
- 首题模板按实际抽中的题目ID、体验线、关系和单题剧本缓存。预留题尚未实际玩过时可继续复用；预留题已进入最近记录时，新局重新分配。结算页下一局预演与返回准备页保持同一题，不重复抽取。
- 最近12次出题保存为 `smart-cabin-riddle-history-v1`，只记稳定ID。加载页、后台预取、未开始就重置均不计数。实际开题同一轮只记一次，刷新后保留；存储不可用时退化为当前页面内存，不阻塞游戏。
- 未来题预演只携带该题新提示、空的问答和事实历史，不再继承当前题公开线索。
- 新增题在网络失败时不沿用原10题的硬编码事实。例如猫不能被本地兜底回答成“没有生命”。无法判断时明确暂不可判断，不新增事实、不计提问次数；答对快速确认仍沿用现有独立规则。
- 题库整理和抽样通过不等于91题已完成事实、同义答案与全年龄用户测评；本次不自动扩展接受答案别名。
