# 环境应景题库 V1

日期：2026-10-22。内容草案，尚未替换运行中的题库。

共 7 种环境，每种 5 道，共 35 道。车库、隧道不准备专属题目。

## 使用方式

- “玩家可见题面”用于提示面板；谜底、接受答案和主持人事实资料仅供后台判题与回答，不能提前展示给玩家。
- 这些是猜谜题目，不是模拟乘客的提问链。模拟乘客仍根据每题内容做预演，实际回答仍由实时主持人生成。
- 沿用现有换题边界：环境改变后准备下一题，自然换题时使用；当前题的谜底、次数和已确认事实保留。
- 题面用于打开猜测范围，不要求玩家只凭一句话立即得出唯一答案；玩家可以继续问是／否属性问题。
- 难度“入门／适中”是内容编排建议，尚未经真实玩家测评。
- 应景只表示主题匹配，不代表系统真的看到了窗外的具体物体。不能仅因题目是瀑布、晚霞或萤火虫，就声称已经检测到它。
- 求助时只重述该题已经展示的公开线索；结构化题库中的事实资料不等于已经公开的提示。
- 题面涉及的物品不构成要求驾驶员观察、寻找或操作的任务。

完整结构化内容见同目录 `ENVIRONMENT_RIDDLE_BANK_V1.json`。每题保留现有基础字段 `answer / theme / hint`，另外附上编号、环境、接受答案、难度和三条事实资料。后续接入时还需按七种环境补齐选题映射；这份文件目前没有自动被运行代码加载。

## 后续接入说明

1. 先审核题面和接受答案范围；可在表格中直接修改，接入前同步到 JSON。
2. 使用 `environment` 区分七种具体环境。城市白天与城市夜晚的 `theme` 均沿用“城区”，但环境匹配时须保留昼夜区别。
3. 切换到车库或隧道时，不从本文件指定专属题目，按现有未出题顺序回退。
4. 本局已经出过的题不重复使用。若单局需要 6 题而某环境只有 5 道，可从其他未出题中选择剩余题，不重复凑数。
5. `facts` 作为后台事实资料使用；`aliases` 需经过实际判题接入才生效。当前前端尚未因为生成这份文件就自动支持这些字段。
