# V1.4 UI 实现记录

## 当前状态

V1.4 已进入 UI 基础落地阶段。本轮以 Figma Page 1 的页面为视觉来源，完成了中控屏三种关键状态的代码化承载：

- 游戏准备页
- 游戏进行中页
- 答案揭晓页与结算页的统一结构

Figma 只负责视觉坐标、尺寸、切片和效果参考；游戏文案、Workflow 契约和交互逻辑继续以项目现有代码与产品文档为准。

## 已实现内容

- 游戏准备页、游戏中、揭晓、结算均支持独立背景和主持人人偶资源。
- Figma 导出的 PNG/SVG 资源统一放在 `assets/figma-*`。

### 2. 游戏准备页

- 增加准备页 Logo、背景、光束、环形马赛克、马赛克氛围背景和开始按钮切片。

### 3. 主持人 Sprite Sheet 与音频

主持人动画已使用透明 Sprite Sheet + Canvas 播放，运行时资源由 `RESOURCE_CONFIG.host` 统一管理：

| 状态 | 资源 | 播放方式 | 结束行为 |
| --- | --- | --- | --- |
| 默认 | `host-normal.json` + `host-normal.webp` | 32 帧、10fps、循环 | 持续待机 |
| 说话 | `host-speak.json` + `host-speak.webp` | 有效 42 帧、10fps、循环 | 忽略越出大图范围的末尾帧；主持人气泡消失后停止并恢复当前状态 |
| 思考 | `host-thinking.json` + `host-thinking.webp` | 40 帧、10fps、单次 | 隐藏气泡，播放完成后回默认 |
| 比心 | `host-heart.json` + `host-heart.webp` | 27 帧、10fps、单次 | 由上层状态逻辑回到默认 |
| 答对 | `host-yes.json` + `host-yes.webp` | 40 帧、10fps、单次 | 进入下一题或重置时回默认 |

所有 Sprite Sheet 使用 `6×7` 网格，每帧源尺寸 `720×720`，Canvas 显示区域固定为 `564×572`。JSON 用于记录资源的帧数、列数、行数和 fps；当前资源尺寸已经统一，运行时按固定网格切帧，避免不同浏览器对视频透明通道的支持差异。

答对状态额外加载 `host-yes.mp3`，按资源配置延迟 `180ms` 播放，音量为 `0.85`。音频加载或解码失败时，前端播放内置答对提示音作为 fallback。说话、默认、思考和比心状态不播放主持人音频。旧的 `host-yes.webm` 不再作为运行时资源。

### 4. 主持人气泡

- 所有页面统一增加指向主持人人偶的小三角。
- 小三角按 Figma 内层图标的 `26 x 21` 尺寸用 CSS 还原，并随气泡高度自动移动。
- 旧的空 SVG 气泡资源不再显示，避免资源为空时页面缺少指向关系。
- 普通主持人话术显示气泡时切换到 `host-speak` 循环动画；气泡隐藏时停止该动画。答对、比心等专用一次性状态保留各自动画，不被普通说话动画覆盖。
- 乘客提问触发本地兜底回复时，主持人延迟 `500ms` 再显示回复，避免网络失败时立即出声；正常 Workflow 返回和预生成提问链不增加这段延迟。
- 气泡文字继续按内容长度切换字号和高度；长文本在最小字号下超过 4 排时截断。

### 5. 透明切片阴影规则

阴影必须加在带透明通道的图片元素上，而不是外层按钮或容器：

```css
.ready-logo {
  filter: drop-shadow(4px 4px 30px rgba(0, 0, 0, 0.6));
}

.ready-start-button img,
.summary-continue img {
  filter: drop-shadow(0 2px 30px #6d30bd);
}
```

这样阴影会沿非透明像素轮廓生成，不会在切片透明区域形成矩形阴影。

### 6. 手动控制区

- 保持原有时间轴、场景切换、车速、环境、事件和副驾输入逻辑不变。
- 整体改为近黑与深蓝灰组成的座舱控制台底色，蓝灰用于普通信息，紫色用于参数选中，绿色用于开始、发送和继续等正向操作，红色只用于急刹和重置等高风险操作。
- 深色输入框、参数按钮和操作栏使用统一边框层级；接口就绪状态使用青绿色，与参考图的暗色控制台语义保持一致。
- 建立“当前演示场景 -> 模拟操作 -> 参数组 -> 副驾输入”的信息层级。
- 手动控制区不显示公网/本地、版本号和代理状态，避免演示时出现技术实现信息。
- 开始模拟使用白底黑字；场景切换使用绿底白字；暂停模拟使用白底黑字，暂停后切换为紫色“继续模拟”；重置使用绿色按钮并保持可用。
- 场景名称和场景切换文字使用绿色，场景切换按钮左侧带双向切换图标，与重置使用的回转图标明确区分。
- 暂停模拟左侧显示暂停图标，切换为继续模拟时自动显示播放图标；重置模拟左侧显示回转图标。
- 急刹打断与其他事件按钮使用统一深蓝灰样式，不再单独使用红色。
- 开始前的参与说明使用绿色文字；提问栏使用无边框的“副驾：”文本标签，不显示状态圆点。
- 开始模拟按钮使用轻微循环缩放引导点击，悬停或聚焦时暂停，并兼容系统减少动态效果设置。
- 提问栏固定为真实副驾，不增加座位选择控件。
- 座舱区新增重要事件显示区：按 Figma 的 `x=43、y=310、h=56` 和自适应宽度实现，使用 `important-event-icon.svg`；事件出现时从左向右展开，停留 `5s` 后从右向左收起。手动事件和黄金时间轴事件共用同一显示状态。

### 7. 游戏进行中倒计时与题目提示

- 每道题单独计时 `90s`，暂停模拟时暂停计时，继续模拟时扣除暂停时长后继续。
- 倒计时环按 Figma 的 `46px` 外径、`19px` 半径和 `8px` 线宽绘制，不在环心显示数字。
- 环形进度从 `12:00` 起沿顺时针方向消退；当前使用 Canvas 绘制，避免不同浏览器对 SVG 描边起点和方向的差异。
- 剩余时间不超过 `10s` 时，中控屏四周显示红色闪烁边框；倒计时结束且无人答对时自动进入下一题。
- 新题开始时先显示“第 N 题”`3s`，期间隐藏倒计时环和“剩余可提问”数字；随后显示题目提示内容。
- 每题开始 `10s` 后显示答案字数提示，出现时使用 `600ms` 放大动画，最大放大到 `200%`。
- “剩余可提问”数字变化时播放短暂滚动动效；乘客气泡出现时播放轻提示音，音量为 `0.35`。

## 资源与加载约定

- Figma 导出资源与项目规范文件的映射统一记录在 `docs/ASSET_MANIFEST.md`。
- 首屏准备页使用的背景、Logo、主持人和按钮资源保留高优先级加载。
- 非当前页面资源通过页面状态切换使用，后续可继续改为预加载队列或懒加载。
- 准备页按当前黄金体验线的环境配置显示座舱背景；配置为 `车库` 或 `隧道` 时使用对应座舱资源，其他场景直接使用对应室外环境图。中控屏准备页仍固定使用 `screen-default.png`，车库和隧道也使用该默认中控背景。
- 游戏进行中手动或时间轴触发环境切换时，右侧座舱背景立即切换；中控屏背景延迟 `2s` 同步切换，并在中控屏背景实际完成替换的同时显示对应环境播报 `3s`，例如“我们来到市区啦，周围热闹起来了。”；连续切换会取消上一条待执行的中控同步和环境播报。
- 游戏结算页固定使用 `screen-scenic-sunset.png`，不再跟随当前车外环境切换；结算页主持人进入默认 `host-normal` 循环动效；结算页 `figma-summary-light-ring.png` 以约 `4s` 呼吸节奏循环调整透明度，形成柔和闪烁效果。
- 主持人 Sprite Sheet 需要同时检查 JSON 网格、透明通道、帧数、fps 和文件体积；答对状态另检查 MP3 的延迟与音量配置。
- 新增大图、Sprite Sheet 或音频前先检查尺寸、格式、透明通道和文件体积。

### Safari 座舱背景重绘

- Safari 17 曾出现准备页切换场景后，场景名称、乘客以及背景图片地址和解码像素都更新，但显示仍停留在旧背景的情况；开始游戏后背景恢复更新。单纯修改缓存或场景排列不能解决该绘制问题。
- 新背景加载成功后替换完整图片节点，并同步重建座舱玻璃层，刷新 WebKit 合成画面；移除座舱背景图片的 `backface-visibility: hidden`。玻璃模糊调整为 1px。
- 中控屏背景加载成功后同步重建游戏提示面板，刷新其 `backdrop-filter` 合成快照，避免面板继续显示上一张背景的模糊效果。
- 相同资源不重复加载；快速切换时忽略过期请求；图片加载失败时保留当前背景，并允许后续重试。
- 验证：Safari 17 连续六次场景切换的图片加载与节点更新正常，WebKit 截图确认车库切换为城市夜景；用户已确认 Safari 准备页右侧背景可以正常切换。
- 本地代理需正确返回 `.webp` 的 `image/webp` 和 `.mp3` 的 `audio/mpeg`。
- 中控屏不再使用 `figma-playing-mosaic.png` 和 `figma-reveal-mosaic.png`，两张已删除并清理 HTML/CSS 引用。
- 不要把 Figma 的临时导出文件、截图和渲染脚本放入生产资源目录；临时文件统一放在 `tmp/`。
